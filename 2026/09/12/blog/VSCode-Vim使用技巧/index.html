VSCode Vim初体验，以及一些技巧

记法：外接键盘按 Win，Mac 上这一颗键就是 Command。正文写成 Win+Shift+E（即 Command+Shift+E），方便对照。

环境配置

本篇默认已经装了 VSCodeVim。

文件树 ↔ 编辑器

Win+Shift+E（即 Command+Shift+E）在这两个状态之间切换：

  • 焦点在当前文件里 → 切到左侧文件树
  • 焦点在左侧（文件树，或下面那块空区域）→ 切回当前已经打开的那份文件

对应命令是 workbench.view.explorer（Show Explorer / Toggle Focus）。不必限定 Normal 模式。

只显示/隐藏整条侧栏是 Win+B（即 Command+B），和切焦点不是同一件事。

也可以用 Win+1（即 Command+1）把焦点直接送进第一组编辑器。分屏时第二组是 Win+2（即 Command+2）。Esc 一般只取消选中，不会切回来。

文件树里移动和打开

焦点在文件树、且没在重命名输入框时（VSCodeVim 默认绑定）：

键 作用
j / k 下一个 / 上一个
l 打开文件；文件夹则展开（焦点进编辑器）
Space 打开当前文件；焦点常留在文件树，可以接着 j / k
h 折叠当前文件夹
o 展开/折叠文件夹

如果一按 j 变成按字母筛选而不是下移，把这项关掉：

Mac 原生命令：资源管理器里 Enter 常常是重命名。打开文件也可以用 Win+↓（即 Command+↓）或 Win+Enter（即 Command+Enter）。l 和 Space 都能打开文件：l 是 VSCodeVim，Space 是 VS Code 默认（filesExplorer.openFilePreserveFocus）。

滚屏

Normal 模式、当前这份文件里。zt / zb 只动画面，光标那一行不变。Ctrl+U / Ctrl+D 翻半页，光标跟着走。

键 作用
zt 把当前行滚到窗口顶部
zb 把当前行滚到窗口底部
Ctrl+U 向上翻半页
Ctrl+D 向下翻半页

翻半页用的是 Control，不是 Win/Command。Mac 上 Win+D（即 Command+D）是多光标选下一个相同词，和 Ctrl+D 不是同一件事。如果 Ctrl+D 走了多光标而不是翻页，加上：

行内找字符

Normal 模式、当前这一行里：

键 作用
f + 字符 正向跳到该字符上
F + 字符 反向跳到该字符上
; 重复上一次 f/F/t/T，同一方向（f 之后就是下一个）
, 重复上一次，反方向（f 之后就是上一个）

t / T 是「停在目标字符前一格」，会改掉 ; / , 跟着重复的那次查找。只想在已经 f 过的结果里往回跳，用 ,，不要再按 t。

全文件搜索

键 作用
/ + 内容 正向搜整份文件
? + 内容 反向搜整份文件
n 同一方向的下一个
N 反方向的上一个

/ 和 ? 都会改掉 n / N 跟着的那次搜索，和行内的 f / ; / , 不是一回事。

回到上次位置

/、G、gg 这类跳走之后：

键 作用
`` 回到跳之前停的地方

再按一次会在这两处之间来回切。
